# Multifamily Underwriting Model (Demo)

**Live demo:** https://nathansabony.github.io/underwriting-model-demo/

A public, simplified version of an underwriting tool I built for a real estate company. The real tool takes a prospective deal's financials and builds an Excel workbook automatically. This demo runs the same core logic in the browser on a **made-up sample deal**:

- 5-year proforma (GPR, vacancy, other income, EGI, opex, NOI, debt service, cash flow)
- Going-in cap rate, cash-on-cash, DSCR, levered IRR, equity multiple
- Upside / base / downside exit scenarios
- Year-3 cash-out refinance check
- Pass/fail checks against user-set benchmarks

Change any input and everything recalculates. No real company data or code is included.

Built with plain HTML, CSS, and JavaScript. Part of my portfolio: https://nathansabony.github.io/
